# Implementation Plan: Engine SRP & DRY Refactoring

**Branch**: `016-engine-srp-refactor` | **Date**: 2026-04-01 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/016-engine-srp-refactor/spec.md`

## Summary

Refactor the engine layer to eliminate ~1,400 lines of duplicated code, split oversized files (orchestrator at 908 LOC, 6 planners averaging 360 LOC each), remove dead code/anti-patterns, and fix React anti-patterns in the TUI layer. No user-facing behavior changes. The approach uses function composition (callback-record pattern) for the planner base, directory-based decomposition for the orchestrator, and module extraction for the implementer layer.

## Implementation Phases

### Phase 1: Planner Base Extraction (P1 — highest impact)

1. Create `src/engine/planners/base.ts` with `buildProjectContext`, `listDir`, `createPlannerBase`
2. Migrate simplest planners first: codex, opencode
3. Migrate aider, shell (config-driven args)
4. Migrate complex planners: agent-sdk (programmatic), claude-code (session chaining)
5. Delete all remaining duplicate `buildProjectContext`/`listDir` copies
6. Verify: `npm test && npm run build`

### Phase 2: Orchestrator Decomposition (P1)

1. Create `src/engine/orchestrator/` directory
2. Extract leaf modules first: `cost.ts`, `tokens.ts` (pure functions, zero risk)
3. Extract `helpers.ts` (shared utilities including new `emitValidationResult`)
4. Extract `final-review.ts` (self-contained subprocess)
5. Extract `task-runner.ts` (retry/escalation cascade)
6. Create `index.ts` with slimmed `runWorkflow` + re-exports
7. Delete original `orchestrator.ts`
8. Update 4 consumer import paths
9. Verify: `npm test && npm run build`

### Phase 3: Implementer Cleanup (P2)

1. Extract `apply.ts` from `implementer.ts`
2. Update imports in `implementers/shell.ts` and tests
3. Extract `openai-stream.ts` from `implementer.ts`
4. Deduplicate `implementTask`/`retryTask` via shared `runOpenAIImplementer`
5. Deduplicate `implementTaskViaShell`/`retryTaskViaShell` via shared `runShellImplementer`
6. Verify: `npm test && npm run build`

### Phase 4: Dead Code & Slop Removal (P2)

1. Delete `escalator.ts`
2. Delete `detectLocalModels()` from `providers.ts`
3. Remove unused imports (`activeProcesses` in opencode, `React` in 3 UI files)
4. Fix redundant types in `summary.tsx` (import from `types.ts`)
5. Remove ~25 unnecessary comments across engine/
6. Fix `catch (err: any)` → `catch (err: unknown)` in validator.ts
7. Fix dead ternary in `planners/shell.ts`
8. Remove dead `codeContext = 0` in `formatter.ts`
9. Remove `?? undefined` defensive patterns in implementer files
10. Verify: `npm test && npm run build`

### Phase 5: React Anti-Pattern Fixes (P3)

1. Fix `picker.tsx` render-phase side effects (move to useEffect)
2. Fix `use-config.ts` (wrap in useMemo)
3. Fix `use-skills.ts` (replace useEffect with useMemo)
4. Fix `input-bar.tsx` (remove prevValue pattern)
5. Fix `review-view.tsx` (sync I/O + derive-don't-sync)
6. Verify: manual TUI testing + `npm test`

### Phase 6: UI Deduplication (P3)

1. Remove local `truncate` from `header.tsx` and `sidebar.tsx` (import from `picker-utils.ts`)
2. Create `ui/markdown.tsx` shared module
3. Update `event-card.tsx` and `review-view.tsx` to use shared markdown
4. Remove unused `import React` from 3 files
5. Verify: `npm test && npm run build`

## Parallel Execution Strategy

Phases 1, 2, and 3 can be executed in parallel by separate agents (they modify disjoint file sets):
- **Agent group A**: Phase 1 (planners/)
- **Agent group B**: Phase 2 (orchestrator/)
