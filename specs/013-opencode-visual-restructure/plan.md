# Implementation Plan: OpenCode Visual Restructure

**Branch**: `013-opencode-visual-restructure` | **Date**: 2026-03-31 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/013-opencode-visual-restructure/spec.md`

## Summary

Clean slate restructure of tiny-spec's codebase and TUI visual design. Moves from Ink 5/React 18 to Ink 6.8/React 19 with incremental rendering, adds Shiki-powered syntax highlighting, replaces box-drawing borders with opencode-style background color stepping and left accent lines, and reorganizes the project from `orchestrator/`+`tui/` to `engine/`+`ui/` (flat) architecture.

## Technical Context

**Language/Version**: TypeScript 5.9+, ESM only (`"type": "module"`)
**Primary Dependencies**: Ink 6.8.0, React 19, Shiki 4.x, ansis, @inkjs/ui 2.x, openai, yaml, simple-git, commander
**Storage**: JSON files (state.json, events.jsonl), Markdown files (spec.md, plan.md, tasks.md)
**Testing**: Vitest (existing test suite, 24 unit + 6 integration tests)
**Target Platform**: macOS (primary), Linux (secondary), Node.js 22+
**Project Type**: CLI tool with TUI
**Performance Goals**: 30 FPS render rate, <5ms per syntax highlight call, <33ms total frame time
**Constraints**: Incremental rendering (line-level diffing), truecolor terminal assumed
**Scale/Scope**: 48 source files → ~50 after restructure, 30 test files

## Implementation Phases

### Phase 1: Framework Upgrade

Upgrade Ink 5→6.8, React 18→19. Verify all existing functionality works. Enable incremental rendering.

**Dependency changes**:
- `ink`: `^5.2.0` → `^6.8.0`
- `react`: `^18.3.0` → `^19.0.0`
- `@types/react`: `^18.0.0` → `^19.0.0`
- New: `shiki` (^4.0.0), `ansis` (^3.0.0)

**Render call update**:
```tsx
render(<App />, { incrementalRendering: true, maxFps: 30 })
```

### Phase 2: Project Restructure

Move files to new locations, update all imports. No logic changes — purely mechanical.

Key moves:
- `src/orchestrator/` → `src/engine/`
- `src/tui/` → `src/ui/`
- `src/orchestrator/diff.ts` → `src/utils/diff.ts`
- Update all 30 test files' import paths

### Phase 3: Theme System + Syntax Highlighting

Create `src/theme.ts` (project-level, no React deps) with opencode-inspired palette. Create `engine/highlight.ts` with Shiki singleton importing from `src/theme.ts`. Integrate into diff-view and event-card.

### Phase 4: Visual Redesign

Rewrite UI components to use opencode visual language:
- Remove box-drawing borders from content
- Add `backgroundColor` stepping (3 levels)
- Add left accent lines on user messages
- Compact tool call display (1-line with icon prefix)
- Braille spinner
- Keyboard hints footer
- Markdown rendering in planner text
- Static component for completed events

### Phase 5: Testing & Polish

Update all tests for new structure and visual changes. Verify incremental rendering works. Visual QA.
