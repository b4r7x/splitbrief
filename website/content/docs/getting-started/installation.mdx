## Requirements

SPLITBRIEF requires:

- Node.js 22 or newer
- Git
- macOS or Linux

Windows support is planned but not yet available. SPLITBRIEF is not yet published on npm, so install it from source.

## Install from source

Run these five commands:

```bash
git clone https://github.com/b4r7x/splitbrief.git
cd splitbrief
npm install
npm run build
npm link
```

`npm link` exposes the `splitbrief` binary on your `PATH`. Run `splitbrief --help` to verify the installation.

You also need a planner and an implementer before starting a workflow. The interactive setup can detect supported CLI tools and running local providers; see [Choosing models](/docs/getting-started/choosing-models) before your first run if you have not selected them yet.

Continue with the [Quickstart](/docs/getting-started/quickstart).
