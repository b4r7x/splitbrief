## 4. Aura + scroll — three directions

| direction | what | verdict |
|---|---|---|
| **CSS-only static aura** | hand-placed fragment spans per tier, dot patterns from `radial-gradient` tiles under `mask-image`, hairline traces as pseudo-elements, drift by keyframes | rejected: ~30 hand positions per tier with no keep-clear; masked tiles are a uniform lattice, the reference's fields are sparse and shaped |
| **canvas aura** | one canvas per section drawing dots, traces and glyph strings from seeded noise; the DOM measured for keep-clear | rejected as the whole: a page-tall backing store at DPR 2 is ~120 MB and the text fragments would lose the existing placer, its tests and its hover; kept for the dot fields alone |
| **hybrid** *(chosen)* | DOM fragments through the existing seeded placer (per-section layers, per-section pools, per-section keep-clear); dot fields as small canvases on the ghosts' 7×11 cell grid (`.`/`:`, seeded); the rail as CSS; reveals by one IntersectionObserver adding `.is-in` once; the rail's spark on a CSS `view()` timeline | reuses tested code, keeps the JS ≈ 3–4 KB, and every mechanism is either CSS or a pure seeded function |

Scroll choreography directions considered: (a) CSS `view()` timelines on every reveal — rejected, scrubbed reveals reverse on the way up and the transcript would un-type; (b) IO one-shot for everything including the spark — rejected, the spark *is* the reader's position in the run and wants to be scrubbed; (c) IO one-shot reveals + one scrubbed spark *(chosen)*, `@supports` guarded, reduced motion = the final frame with no observer needed.

## 7. Scroll choreography — the concept

**The run comes down the page: the brief the hero routed leaves the reviewer's seat as a spark on a rail down the right margin, and each section's artefact paints itself in as the spark reaches it — the editor loads the file, the terminal prints the run, the folder fills — once, on arrival, never on the way back up.** Mechanics in §16.6: one `IntersectionObserver` (`rootMargin: 0 0 -30% 0`) adds `.is-in` per section once; the hero's `enter` keyframes (480 ms ease-out, translate 8 px) on the head, notes, callouts and tree with 60 ms steps; panel rows 240 ms each at 12 ms (editor) / 90 ms (terminal) with a 240 ms beat after `FAIL`; the spark on `animation-timeline: view()` over `.rail` (`@supports` guarded; hidden without support); the dot fields shimmer at 2 fps on the ghosts' ticker; the fragments keep §7.5's hover. `prefers-reduced-motion: reduce` and `.no-js` never apply a pre-reveal state.
