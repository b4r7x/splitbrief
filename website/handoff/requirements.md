## Constraints

- C-1 Repo `CLAUDE.md`: never `git add` / `git stage` / `git commit` (a `PreToolUse` hook blocks it); every change stays an unstaged modification; only `website/**` changes.
- C-2 Stack as `website/package.json`: Vite 8, TypeScript 7 strict (`noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`, `verbatimModuleSyntax`, `moduleResolution: bundler`, extensionless imports — the Vite convention), Vitest 5 (`environment: 'node'`, pure modules only), Playwright 1.63 on `channel: 'chrome'` against `vite preview`, Biome 2.5 (2 spaces, 100 cols, single quotes, kebab-case filenames).
- C-3 Code rules: no classes; no comments (a comment survives only by stating a constraint the code cannot); no `any`, no `!`, no `as` beyond `document.querySelector<T>` narrowing (type guards instead); ESM; kebab-case; basename = primary export; no `utils` / `helpers` / `common`; no `index.ts`; features import only `lib/` and their own folder; `main.ts` composes; ≤ 200 lines per file; features flat below 3 files, a folder at 3+; colocated tests for pure functions; e2e in `tests/e2e/*.e2e.ts`; no `Math.random`.
- C-4 CSS rules: cascade layers in `main.css`'s order; tokens only in `tokens.css`; nesting allowed; container queries drive the diagram tier, media queries the page grid; `text-wrap: balance` on headings, `pretty` on paragraphs; `prefers-reduced-motion` honoured in CSS (`motion.css`, `reveal.css`, `aura.css`) and JS (`lib/reduced-motion.ts` start/stop).
- C-5 Crew (ruling 6): implementer `cursor-agent` model `cursor-grok-4.6-xhigh` (headless, brief-only — it sees nothing but its brief); code reviewer `cursor-grok-4.6-high` read-only (`--mode plan`); `--no-escalate` (no takeover — an exhausted ladder stops the run and goes to the owner); render critic and visual-diff writer = a fresh Fable session agent (a cursor seat may run the visual-diff task when it can read images); orchestrator Fable; spec completeness reviewer = a fresh Fable session agent, one pass, review + fix in place (owner 14:20 — no Opus).

## Decisions

- D-1 **FHD = a capped container** (§11 v2): `--content-max` 1392 at ≥ 1600 with the aura full-bleed across 264 px gutters; the lower type steps one notch; the hero changes only its width (diagram 802, stage scale 1). Rejected: a fluid grid to 1920 (the diagram box would be 1042 wide: ghosts in its left 760 px with the claim 280 px away, or a 1179 px stage leaving the fold).
- D-2 **Reveals by IntersectionObserver one-shot + CSS, the spark alone on a scroll timeline** (§16.6): sections paint once on arrival and stay. Rejected: `animation-timeline: view()` on content — scrubbed by definition, it would un-type the transcript on the way up.
- D-3 **Hybrid aura**: CSS for the rail, spark, stops and reveals; JS for the seeded placer, the one-time dot draw + shimmer and the observer. Rejected: an all-JS scroll handler (layout thrash, a second motion system) and an all-CSS aura (no seeded placement, no keep-clear).
- D-4 **One class, `.fragment`, for every hovering string** (the hero's existing name); §16's `.frag`, `.frag--gutter`, `.frag--glyph` are not created — the placer decides positions per tier on every resize, so CSS needs no tier classes. Rejected: renaming the hero's class (three files of churn for a name) or two names for one thing.
- D-5 **The section pools and layer specs live in `features/fragments/pool.ts`**, not `features/aura/pool.ts`: a pool is placer data, and `aura/` must not import `fragments/`. `POOL` keeps its name (no `POOL_HERO`). Rejected: `aura/pool.ts` importing `Layer` from `fragments/` — a cross-feature import the gate forbids.
- D-6 **`ticker.ts` is promoted to `src/lib/ticker.ts`** on its second consumer (the dot shimmer), one brief with the two import edits approved out of bounds. Rejected: a second ticker in `aura/` (57 duplicated lines) or `aura/` importing `diagram/`.
- D-7 **The pure placer moves to `features/fragments/place.ts`** (`mount.ts` keeps the DOM half; `mount.test.ts` becomes `place.test.ts`) so the hero and the three sections share one placer through `main.ts`; `sectionKeepClear` lives in `features/aura/keep-clear.ts` with its own structural `Rect`. Rejected: `aura/layer.ts` calling `fragments/mount.ts` (§13's own file map contradicts §13's rule; the gate would fail).
- D-8 **Opacity channel**: the placer's existing channel 3 (`hash(seed, k, 3, 0)`) scaled to the layer's range; §16.5's `hash(seed, i, 0, 3)` notation names the same channel. Rejected: a new channel layout — it would move the hero's 19 placements.
- D-9 **Pre-reveal state is `opacity: 0` only**; the 8 px rise comes from the `enter` keyframes' `from` (with `fill-mode: both` it shows during the delay, so the render is §16.6's). Rejected: `translate: 0 8px` in the pre-reveal rule — it shifts every keep-clear box measured at load by 8 px and, as the implicit `to` frame, would leave the element 8 px low after the animation.
- D-10 **The pre-reveal rule is scoped to `section:not(.is-in)`** so the animated element's base opacity is 1 once `.is-in` lands (an implicit `to` of 0 would hold the element invisible under `fill-mode: both`).
- D-11 **The capture set is ten PNGs + two JSON per tag**: `-1440`, `-fold`, `-390`, `-1920`, `-1920-fold`, `-1024`, `-768`, `-1920-s02`, `-1920-s03`, `-1920-s04` (a missing section skips its fold) and `-hero-1440.json`, `-hero-1920.json` (the hero boxes, a stable ordered list) — `SHOT_DIR`, `SHOT_TAG`, `SHOT_TIME_MS` stay the whole interface. Rejected: five PNGs with the critic hand-making the section folds (not mechanical) and pixel-diffing the hero against `current-1440.png` (the steps' label widths re-place the seeded fragments, so bytes cannot match; boxes can).
- D-12 **The hero stability check is two-fold**: `diff` of the hero JSON against `p0` (P1 on), and a byte-identical crop of the hero region against `p1` (P2 on; `python3` + PIL `ImageChops.difference(...).getbbox()` = `None`).
- D-13 **The hero fragment count floor is ≥ 18 at 1440×900** (`motion.e2e.ts`), the exact count recorded in `DESIGN.md` §7.5 by the orchestrator after P1. Rejected: keeping `toHaveCount(19)` — the anchors change the steps' label widths, which enter the keep-clear, and the seeded search cascades; a hero seed hunt only if the floor breaks (NG-7).
- D-14 **`hero.css` scopes `.steps` and `.line` under `.hero`, and `motion.css` scopes its three `.steps` selectors the same way** (its `.line` rules already read `.hero h1 .line`): 03's `ol.steps` and 04's breath lines reuse the class names with their own rules (`s03.css`, `s04.css`). Rejected: leaving the unscoped rules — 03's steps would inherit the hero's grid placement and its load-time `enter` entrance (and, because `reveal.css` animates the same `enter` name on `.s03 .steps`, a CSS animation that already ran at load is updated in place rather than restarted, so the steps would snap in instead of revealing — stage 2r), and the breath's `.muted` would be `--ink-4` and its stanza gap `--s-24`.
